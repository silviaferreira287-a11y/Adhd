# ADHD skill

A Claude skill that helps with ADHD: starting tasks, planning the day, staying focused, and getting unstuck when overwhelmed.

## What it does

- **Short, scannable replies** - one question, one tiny next step.
- **Break it down** - big task → small steps of 15 min or less.
- **Plan the day** - max 3 must-dos, buffers, breaks.
- **Focus session** - body doubling and check-ins.
- **Reset** - from frozen to one small action.
- **Calendar** - optional time blocks (always asks first).

## Files

```
adhd-helper/
  SKILL.md              main instructions
  references/
    break-down.md
    plan-day.md
    focus-session.md
    reset.md
```

## Install

Copy the `adhd-helper` folder into `~/.claude/skills/` (Claude Code) or upload it as a skill in Claude settings.

## Your own skill

Put an existing skill you already have in its own folder next to `adhd-helper/`.
